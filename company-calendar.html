"Upcoming events" above is a live read of the real Google Calendar (via a small server-side relay, since browsers can't read Google's calendar feed directly). The full calendar below is Google's own embedded view — no Google Cloud project, no API key, no cost. Both work because each calendar is set to "Make available to public" in Google Calendar's sharing settings. This page only displays events; it can't add, edit, or delete them — to add an event, open Google Calendar directly the way you always have.
